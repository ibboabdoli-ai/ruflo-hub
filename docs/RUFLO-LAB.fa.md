# نصب آزمایشی RuFlo در GitHub

این مرحله فقط روی سرور موقت GitHub Actions اجرا می‌شود. نرم‌افزار روی گوشی یا کامپیوتر شخصی نصب نشده و پس از پایان تست، محیط حذف می‌شود.

## موارد اجراشده

- نصب نسخه ثابت `ruflo@3.56.10` داخل پوشه موقت Runner با `npm`.
- اجرای فرمان‌های `ruflo --version` و `ruflo --help`.
- اجرای `ruflo init` در یک پروژه موقت و بررسی ایجاد فایل‌های تنظیمات.
- اجرای کارها بدون کلید OpenAI/Claude، بدون اجازه تغییر GitHub و بدون اتصال به Proffera.
- بررسی اینکه فایل‌های همین مخزن توسط فرآیند نصب تغییر نکرده باشند.

در این مرحله GitHub Actions از `npm install --ignore-scripts` استفاده می‌کند تا اسکریپت‌های زمان نصب اجرا نشوند؛ بعضی امکانات اختیاری ممکن است با این حالت کار نکنند.

## اجرای دوباره

به تب `Actions` مخزن برو، workflow به نام `RuFlo isolated installation smoke test` را انتخاب کن و `Run workflow` بزن.

## وضعیت دقیق

موفقیت این تست نشان‌دهنده نصب و اجرای مقدماتی در محیط موقت است؛ به معنی راه‌اندازی سرویس دائمی، اتصال به Codex، اجرای واقعی چند ایجنت یا تضمین نبود هزینه در کارهای آینده نیست.

برای نصب دائمی باید یک میزبان مشخص (کامپیوتر شخصی یا سرور) و سطح دسترسی پروژه‌ها جداگانه تعیین شود.
