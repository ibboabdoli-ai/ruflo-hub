# داشبورد RuFlo Hub — نسخه فقط‌خواندنی

صفحه `docs/index.html` یک داشبورد فارسی برای بررسی **فقط اطلاعات عمومی GitHub** دو مخزن `ibboabdoli-ai/ruflo-hub` و `ibboabdoli-ai/Proffera` است. هیچ بک‌اند، API key، کوکی احراز هویت، سرویس پولی یا اجرای مداوم ندارد.

## مشاهده محلی
سه فایل `docs/index.html`، `docs/dashboard.css` و `docs/dashboard.js` باید کنار یکدیگر باشند. صفحه را با مرورگر باز کنید. در صورت عدم اجازه مرورگر به درخواست‌های CORS برای فایل‌های محلی، از یک وب‌سرور استاتیک محلی استفاده کنید. فقط مرورگر کاربر به GitHub درخواست می‌فرستد؛ سرور Proffera هیچ دسترسی نمی‌دهد.

## انتشار رایگان با GitHub Pages (پس از ادغام تأییدشده)
مالک مخزن در GitHub وارد `Settings → Pages → Build and deployment` شود، گزینه **Deploy from a branch** را انتخاب کند، سپس `main` و پوشه `/docs` را انتخاب و Save کند. آدرس معمول پس از انتشار: `https://ibboabdoli-ai.github.io/ruflo-hub/`. **تا وقتی Pages فعال و سایت بازآزمایی نشده باشد، این آدرس را فعال فرض نکنید.**

## محدودیت‌ها
- PRهای ثابت `ruflo-hub#4` و `Proffera#941`، SHA هر PR، نتایج check-run و پروفایل عمومی را می‌خواند.
- هیچ سورس پروژه، کلید، customer data، داده خصوصی، یا محتوای PR دانلود نمی‌کند.
- GitHub API بدون احراز هویت محدودیت نرخ دارد؛ 403، خطا و شواهد ناقص به‌صورت تأییدنشده نمایش داده می‌شوند.
- موفقیت CI به معنی مجوز merge نیست و «پروفایل disconnected» اثبات وضعیت همه سامانه‌های تولید نیست.
- وضعیت زنده RuFlo agents یا Supervisor مشاهده نمی‌شود؛ ابزار فقط نمایشی است. هیچ `push/merge/deploy` یا دسترسی نوشتن به Proffera ندارد.
- این داشبورد عمومی است؛ برای داده‌های خصوصی باید معماری و دسترسی‌ها مستقلاً بررسی شوند.

تست‌ها: `npm test` و `node --check docs/dashboard.js`. انتشار خودکار یا GitHub Pages deployment workflow در این PR فعال نمی‌شود.
